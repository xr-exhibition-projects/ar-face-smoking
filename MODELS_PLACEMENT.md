# Размещение model_assets для сборки exe

## Где разместить model_assets

После сборки exe файла, папку `model_assets` нужно разместить **в той же директории, где находится exe файл**.

### Структура после сборки:

```
dist/
└── VisoMasterAR/
    ├── VisoMasterAR.exe          ← exe файл
    ├── dependencies/              ← автоматически включено в сборку
    ├── assets/                   ← автоматически включено в сборку
    ├── app/                      ← автоматически включено в сборку
    ├── animation_config.json     ← автоматически включено в сборку
    └── model_assets/             ← НУЖНО СКОПИРОВАТЬ ВРУЧНУЮ
        ├── *.onnx
        ├── *.pth
        ├── *.pkl
        ├── dfm_models/
        └── liveportrait_onnx/
```

## Как это работает

1. При запуске exe, код определяет папку с exe файлом через `sys.executable`
2. Устанавливается переменная окружения `VISOMASTER_MODELS_DIR` на путь `{папка_с_exe}/model_assets`
3. Все модули используют эту переменную для поиска моделей

## Важно

- Папка `model_assets` должна быть в той же директории, что и `VisoMasterAR.exe`
- Структура внутри `model_assets` должна быть сохранена (включая подпапки `dfm_models/` и `liveportrait_onnx/`)
- Если `model_assets` не найден, приложение может не работать корректно
